Werbebriefe und Kundenbriefe sind Serienbriefe.

[Was ist ein Serienbrief?](/de/blog/serienbrief)

Die Brief-Vorlage können Sie aus einem MS Office- OpenOffice- bzw. einem anderen Dokument (Epub, Xml, Mht, Html) importieren, oder auch komplett neu im Edi erstellen.

Die berechneten Felder werden von Edi als eine Excel-Datei (Xlsx, Xls) gespeichert.


<img-view src="/images/de/blog/kudenbrief-schreiben/100-serienbrief-felder-als-berechnete-formeln-definieren.png" 
            srcquery="width=500"
            alt="Serienbrief-Felder in der Kalkulationstabelle definieren"
            link></img-view>

Die einzelnen Felder können Sie miteinander verknüpfen, summieren oder automatisch berechnen lassen. Zur Verfügung stehen Ihnen viele mathematische und statische Formeln. 

Numerische Werte wie Währung oder  Datum können Sie formatieren. Überdies können Sie die Bedingungen WENN -> DANN anwenden.

Bestimmte Felder können Sie z.B. nur für ausgewählte Mitarbeiter freigeben.

Sind die berechneten Felder komplett und formatiert, so aktivieren Sie die Text-Ansicht.

**Die Serienbrief-Felder werden automatisch aus der Daten-Ansicht in die Feld-Auflistung übernommen.**

Positionieren Sie die Serienbrief-Felder auf dem Text-Dokument.

<img-view src="/images/de/blog/kudenbrief-schreiben/400-serienbrief-felder-auf-das-dokument-mit-maus-schieben.png" 
            srcquery="width=500"
            alt="Serienbrief-Felder einem Text-Dokument hinzufügen"
            link></img-view>

Sie können alle Datensätze in demselben Dokument speichern (Report), oder ein Datensatz pro Dokument festlegen (Kundenbrief).
